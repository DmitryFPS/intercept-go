# Работа администратора с InterceptServer

## Первый запуск

1. Распакуйте сервер в постоянную папку мини-ПК.
2. Положите рядом рабочий `word_template.docx`, если используется Word-направление.
3. Запустите `InterceptServer.exe`.
4. Откройте раздел **Транспорт** и укажите токен серверного бота, ID закрытой транспортной супергруппы и необязательную ссылку-памятку.
5. Добавьте серверного бота администратором в транспортную супергруппу и включите для него Bot-to-Bot Communication Mode в BotFather.
6. Нажмите **Проверить и сохранить**. Сервер проверит токен, доступ к группе и отключит webhook перед запуском long polling.

## Добавление точки

Для каждой точки создайте отдельного бота через BotFather и включите Bot-to-Bot Communication Mode. Добавьте его в транспортную супергруппу с правом отправлять сообщения.

В сервере откройте **Точки → Добавить точку** и укажите:

- понятное название;
- токен бота точки;
- тему транспортной группы;
- полный путь к `main.sqlite` на компьютере точки;

Нажмите **Проверить и скачать JSON**. Сервер вызовет `getMe`, проверит возможность бота писать в указанную тему и сразу отдаст готовый файл оператору.

## Направления

Направление не связано с названием «Шабашка» или «39-ка». Это запись одного из типов:

- Telegram-группа или канал;
- Telegram-тема;
- Word в локальную или сетевую папку.

Для каждого направления есть собственные настройки, состояние, очередь и журнал. Новое направление ничего не получает, пока администратор явно не включит маршруты.

## Матрица маршрутов

В строках находятся позиции EAVC и системная строка неопознанных данных. В столбцах находятся направления. Каждая ячейка имеет одно из состояний:

- **Не отправлять**;
- **Отправлять**;
- **На проверку**.

Для Telegram-направления действие «Отправлять» также содержит тему. Для Word-направления оно содержит профиль шаблона и папки.

Изменения в таблице сначала являются локальным черновиком. Кнопка **Опубликовать новую версию** проверяет всю матрицу и атомарно включает её. В блоке истории можно восстановить предыдущую матрицу; восстановление сохраняется как новая версия.

## Разбор неопознанного события

Сервер отправляет исходное название в General направления, выбранного для действия **На проверку**, с красным заголовком. Если строка близка к известной, сообщение содержит подсказку. Администратор проверяет исходное название и при необходимости добавляет точную новую позицию в матрицу. Похожее название никогда не подставляется и не маршрутизируется автоматически.

На странице **Обзор** доступна кнопка **Скачать диагностику**. ZIP содержит безопасный статус, историю версий правил и ротируемые журналы, но не содержит токены, ключи или пароли.
