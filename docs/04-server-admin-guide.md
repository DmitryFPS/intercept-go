# Работа администратора с InterceptServer

## Первый запуск

1. Распакуйте сервер в постоянную папку мини-ПК.
2. Положите рядом рабочий `word_template.docx`, если используется Word-направление.
3. Запустите `InterceptServer.exe`.
4. Мастер попросит токен серверного бота, ID закрытой транспортной супергруппы и ссылку-памятку.
5. Добавьте серверного бота администратором в транспортную супергруппу и включите для него Bot-to-Bot Communication Mode в BotFather.
6. Нажмите **Проверить транспорт**. Мастер не завершится, пока бот, группа и получение обновлений не проверены.

## Добавление точки

Для каждой точки создайте отдельного бота через BotFather и включите Bot-to-Bot Communication Mode. Добавьте его в транспортную супергруппу с правом отправлять сообщения.

В сервере откройте **Точки → Добавить точку** и укажите:

- понятное название;
- токен бота точки;
- тему транспортной группы;
- полный путь к `main.sqlite` на компьютере точки;
- при необходимости период чтения.

Нажмите **Проверить**. Сервер вызовет `getMe`, проверит доступ к группе и отправку тестового пакета. После успешной проверки нажмите **Создать файл настроек** и передайте JSON оператору.

## Направления

Направление не связано с названием «Шабашка» или «39-ка». Это запись одного из типов:

- Telegram-группа или канал;
- Telegram-тема;
- Word в локальную или сетевую папку.

Для каждого направления есть собственные настройки, состояние, очередь и журнал. Новое направление ничего не получает, пока администратор явно не включит маршруты.

## Матрица маршрутов

В строках находятся позиции EAVC и системная строка неопознанных данных. В столбцах находятся направления. Каждая ячейка имеет одно из состояний:

- **Не отправлять**;
- **Отправлять**;
- **На проверку**.

Для Telegram-направления действие «Отправлять» также содержит тему. Для Word-направления оно содержит профиль шаблона и папки.

Изменения сначала являются черновиком. Кнопка **Проверить маршруты** показывает получателей для тестовых событий. Кнопка **Опубликовать** атомарно включает новую версию. Предыдущую версию можно вернуть.

## Разбор неопознанного события

Сервер показывает исходное название, причину и похожие известные позиции. Администратор может:

- связать написание с существующей позицией;
- создать новую позицию правил;
- отклонить событие;
- после решения явно нажать **Отправить сейчас**.

Похожее название никогда не подставляется автоматически.
