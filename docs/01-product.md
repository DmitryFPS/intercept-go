# Описание продукта

## Границы текущей работы

В новую реализацию входят две программы:

1. `InterceptClient` — переносимая программа на каждой точке: Текстиль, Селидово, Весёлое и последующие точки.
2. `InterceptServer` — центральная переносимая программа на мини-ПК.

EAVC, EAVC HUB и EAVC SERVER сейчас не переписываются: их исходный код и рабочая среда недоступны. Новый клиент совместим с доступной схемой `main.sqlite` и открывает эту базу только для чтения. Ни одна операция нового клиента не изменяет данные EAVC.

## Что фактически доступно из EAVC

Текущая таблица `intercept_items` хранит идентификатор самого перехвата, его UUID, текст, подразделение (`unit_name`), частоту, код группы, автора и время изменения. Она не хранит надёжную ссылку на строку каталога позиций.

Поэтому новый клиент передаёт:

- UUID перехвата EAVC;
- локальный числовой ID перехвата;
- название выбранного подразделения;
- частоту и код группы;
- содержание и служебные даты;
- стабильный ID события транспортного протокола UUID v7;
- идентификатор точки и версию клиента.

Если в будущей версии EAVC появится `catalog_uuid`, клиент обнаружит поле по схеме и начнёт передавать его без изменения протокола. До этого сервер маршрутизирует только по точному нормализованному названию. Нечёткое совпадение служит подсказкой человеку и никогда автоматически не включает маршрут.

## Рабочий поток

1. Оператор работает только в EAVC.
2. Клиент обнаруживает новую или изменённую запись в `main.sqlite`.
3. Клиент создаёт UUID v7, помещает снимок записи в долговечную локальную очередь и шифрует пакет индивидуальным ключом точки.
4. Бот точки отправляет файл пакета в тему этой точки закрытой транспортной супергруппы.
5. Серверный бот получает файл, проверяет отправителя, расшифровывает пакет и подтверждает событие.
6. Сервер сохраняет исходное событие до выполнения внешних действий.
7. Матрица маршрутов создаёт отдельное задание для каждого получателя.
8. Telegram-направления и файловые направления выполняются независимо. Сбой одного направления не повторяет уже успешно выполненные другие направления.
9. Клиент получает подтверждение и переводит событие из очереди в архив доставки.

## Термины

- **Точка** — компьютер с EAVC и InterceptClient, например «Текстиль».
- **Позиция** — выбранное в EAVC подразделение, значение `unit_name`.
- **Транспортная группа** — закрытая техническая Telegram-супергруппа, через которую клиенты передают зашифрованные пакеты серверу.
- **Тема точки** — отдельная тема транспортной группы, назначенная одной точке.
- **Направление** — внешний получатель: Telegram-группа, тема, канал, Word-папка или другой поддержанный адаптер.
- **Маршрут** — явное решение, отправлять ли конкретную позицию в конкретное направление.
- **General** — общая тема Telegram-группы; для неё используется `message_thread_id = 0` в конфигурации приложения.

## Начальная матрица маршрутов

Маршруты не зашиваются в код обработчиков. При первом запуске сервер загружает встроенный JSON-шаблон с известными правилами, а дальнейшие изменения сохраняет версиями в собственной базе.

### Шабашка

- тема `592`: `2 об 3 обр ОсН "Спартан" НГУ`;
- тема `2091`: `мпб 155 омбр`;
- тема `591`: `10 ошб 59 ошбр`.

Для этих позиций Word-направление выключено.

Все новые, ошибочные и неопознанные названия направляются только в General группы «Шабашка» с заметным заголовком `НОВОЕ ИЛИ ОШИБОЧНОЕ ПОДРАЗДЕЛЕНИЕ`. Word для них не создаётся до решения администратора.

## Отложенный режим

Оператор EAVC обозначает задержанный перехват, добавляя к названию подразделения окончание `(отложенный режим)`. Это информационная пометка, а не запрет доставки.

Клиент сохраняет полное название для Telegram и Word, а для поиска маршрута временно отбрасывает только это точное окончание. Поэтому `2 об 3 обр ОсН НГ (отложенный режим)` использует тот же маршрут, что `2 об 3 обр ОсН НГ`, но во всех выходных материалах остаётся с пометкой. Если EAVC когда-либо добавит отдельное поле `source_mode`, клиент тоже передаст его, однако сам режим не отключает ни Telegram-, ни Word-направление.

В Word по умолчанию используется номер сети `313`; он остаётся редактируемой настройкой направления.
