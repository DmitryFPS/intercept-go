# Критерии готовности

Пункт отмечается только после автоматической или документированной ручной проверки.

## Код и архитектура

- [x] В репозитории нет исходного кода Python и производственных секретов.
- [x] Домен и прикладные сценарии не импортируют инфраструктурные пакеты.
- [ ] Код отформатирован, `go vet ./...` и обычные тесты проходят; detector race ожидает машину с GCC/CGO.
- [x] Экспортируемые типы и нетривиальные инварианты документированы.
- [x] Миграции состояния идемпотентны и проверяются тестами.

## Клиент

- [x] Клиент поставляется одной переносимой папкой и не требует администратора.
- [x] EAVC SQLite открывается только для чтения.
- [x] Новые и изменённые записи переживают отключение интернета и перезапуск.
- [x] Повторная отправка не создаёт повторной обработки.
- [x] Оператор видит разницу между загрузкой в Telegram и подтверждением сервера.
- [x] Диагностический архив не включает файлы настроек или базы с секретами.

## Сервер

- [x] Одновременный приём от трёх тестовых точек проверен интеграционным тестом.
- [x] Неверный бот, тема, ключ и повреждённый пакет безопасно отклоняются; конфликт UUID проверяется хранилищем.
- [x] Маршрутизация воспроизводит утверждённую начальную матрицу.
- [x] Неопознанное название попадает только в General «Шабашки» и не создаёт Word.
- [x] Ошибка одного направления не повторяет успешные направления.
- [x] Маршруты версионируются, проверяются до публикации и восстанавливаются новой версией.
- [x] Новые направления добавляются без пересборки программы.
- [x] Word создаётся из шаблона и атомарно доставляется в папку назначения.
- [x] Очереди продолжаются после перезапуска процесса.

## Поставка

- [x] Сборка воспроизводима одним PowerShell-скриптом.
- [x] Архивы клиента и сервера распакованы в чистые каталоги и запущены smoke-тестом.
- [x] Для файлов опубликованы SHA-256.
- [x] Проверены пути с пробелами и кириллицей.
- [x] Собранные EXE не требуют Python, Go, Git и среды разработки на целевом ПК.
- [x] Руководства оператора и администратора соответствуют фактическому интерфейсу.

## Приёмка на рабочей инфраструктуре

- [ ] Импорт реального JSON проверен на чистом профиле Windows.
- [ ] Выполнен сквозной тест с реальными ботами, тремя темами и серверным ботом.
- [ ] Проверена запись готового DOCX в рабочую SMB-папку MikroTik.
