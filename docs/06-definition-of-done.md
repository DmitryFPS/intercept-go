# Критерии готовности

Система называется готовой к передаче только после выполнения всех пунктов.

## Код и архитектура

- [ ] В репозитории нет исходного кода Python и производственных секретов.
- [ ] Домен и прикладные сценарии не импортируют инфраструктурные пакеты.
- [ ] Код отформатирован `gofmt`, проходят `go vet ./...` и тесты с detector race.
- [ ] Экспортируемые типы и нетривиальные инварианты документированы.
- [ ] Миграции состояния идемпотентны и проверяются тестами.

## Клиент

- [ ] Клиент поставляется одной переносимой папкой и не требует администратора.
- [ ] Импорт готового JSON проверен на чистом профиле Windows.
- [ ] EAVC SQLite открывается только для чтения.
- [ ] Новые и изменённые записи переживают отключение интернета и перезапуск.
- [ ] Повторная отправка не создаёт повторной обработки.
- [ ] Оператор видит разницу между загрузкой в Telegram и подтверждением сервера.
- [ ] Диагностический архив не содержит секретов.

## Сервер

- [ ] Приём от трёх тестовых точек работает одновременно.
- [ ] Неверный бот, тема, ключ, UUID или повреждённый пакет безопасно отклоняются.
- [ ] Маршрутизация воспроизводит утверждённую начальную матрицу.
- [ ] Неопознанное название попадает только в General «Шабашки» и не создаёт Word.
- [ ] Ошибка одного направления не повторяет успешные направления.
- [ ] Маршруты версионируются, проверяются до публикации и откатываются.
- [ ] Новые направления добавляются без пересборки программы.
- [ ] Word создаётся из шаблона и атомарно доставляется в папку назначения.
- [ ] Очереди продолжаются после аварийного завершения.

## Поставка

- [ ] Сборка воспроизводима одним PowerShell-скриптом.
- [ ] Архивы клиента и сервера распакованы в чистые каталоги и запущены smoke-тестом.
- [ ] Для файлов опубликованы SHA-256.
- [ ] Проверены пути с пробелами и кириллицей.
- [ ] Проверена работа без Python, Go, Git и среды разработки на целевом ПК.
- [ ] Руководства оператора и администратора соответствуют фактическому интерфейсу.
