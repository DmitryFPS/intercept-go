# Работа оператора с EAVC Connect — Рабочая точка

## Первый запуск

1. Распакуйте выданный архив в отдельную папку на рабочем столе.
2. Откройте папку и дважды нажмите `EAVC Connect Station.exe`.
3. Настройки из готового комплекта применятся автоматически. Никакой код вводить не нужно.
4. Если база не найдена сама, нажмите **Найти EAVC**. Расширенный поиск по всем дискам нужен только когда быстрый поиск ничего не нашёл.
5. Если найдено несколько баз, выберите рабочую по пути и времени изменения. Архивную копию выбирать нельзя.
6. Нажмите **Проверить связь с центром** и дождитесь надписи **Связь проверена**.
7. Дождитесь зелёного сообщения **Программа работает**.

Никакие IP-адреса, токены, номера Telegram-тем и ключи вводить не нужно.

Программа хранит очередь и журналы рядом с EXE. Поэтому текущей учётной записи Windows нужны права записи в папку программы, `data`, `logs` и существующий файл `data/client.db`. Это важно и для автозапуска после перезагрузки: он работает под обычной учётной записью. При сообщении «Нет прав на запись» перенесите всю папку в место, где эта учётная запись может изменять файлы, либо обратитесь к администратору за правом изменения именно этой папки и её файлов. Запуск от имени администратора лишь временно скрывает проблему.

## Что видно на главном экране

- **Программа работает** — клиент читает EAVC и может связываться с Telegram.
- **Ожидает интернет** — данные сохранены на компьютере и будут переданы автоматически.
- **Нужны настройки** — конфигурация ещё не загружена или устарела.
- **Ошибка базы EAVC** — указанная база не найдена либо её схема не поддерживается.
- **Ошибка Telegram** — бот удалён из группы, тема закрыта, токен отозван или Telegram недоступен.

В карточке точки показан её постоянный ID. Сообщите его администратору вместе с номером точки, если потребуется повторно скачать настройки или разбирать журнал.

Если связи нет, программа повторяет отправку. Более позднее сообщение одного подразделения не обгонит предыдущее; другие подразделения этой точки продолжают отправку. Через 30 минут от времени изменения в EAVC неотправленное событие переводится в отдельный счётчик и больше не рассылается.

Путь к EAVC хранится только на этом компьютере. Загрузка обновлённого JSON не стирает его. Поле можно заполнить папкой EAVC либо полным путём к `main.sqlite`; клиент обязательно проверит структуру базы до запуска.

Отдельно показываются:

- время последнего чтения EAVC;
- время последней загрузки пакета;
- время последнего подтверждения сервером;
- число ожидающих событий;
- короткая понятная причина последней ошибки.

Все четыре счётчика очереди открываются нажатием. Для каждого сообщения видны
позиция, время, понятное состояние и исходный текст. Списки **Ожидают отправки** и
**Загружены, ждут центр** доступны только для просмотра: программа сама убирает
из них обработанные сообщения. Списки **Подтверждены** и **Не отправлены старше
30 минут** можно очистить вручную. Активные данные удалить этой кнопкой нельзя.

Оператору доступны только **Старт**, **Стоп**, **Обновить**, **Загрузить
настройки**, **Проверить связь с центром**, **Скачать диагностику** и блок выбора
базы EAVC. Новый JSON используется лишь для обновления; клиент принимает его
только от того же центра, который подготовил первоначальный комплект.

## Что делать при ошибке

Нажмите **Скачать диагностику** и передайте полученный ZIP администратору. Архив включает версии, обезличенное состояние проверок и журналы; токены и ключи в него не попадают.

Не изменяйте файлы в папке `data` вручную и не копируйте настроенную папку на другую точку. Для новой точки нужен отдельный конфигурационный файл.
