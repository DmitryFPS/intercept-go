INTERCEPTSERVER — ПЕРВЫЙ ЗАПУСК

1. Распакуйте архив в постоянную папку на мини-ПК.
2. Дважды нажмите InterceptServer.exe.
3. В разделе «Транспорт» укажите серверного Telegram-бота и ID закрытой супергруппы.
4. В разделе «Куда отправлять» настройте группы Telegram и папку Word.
5. В разделе «Точки» создайте отдельный JSON для каждой точки и передайте его оператору.
6. Проверьте матрицу в разделе «Правила отправки» и опубликуйте её.

Установка, Python, Go, VPN, белый IP и права администратора не нужны.
Для каждого клиента нужен отдельный Telegram-бот и отдельная тема транспортной группы.
У серверного и клиентских ботов в BotFather должен быть включён Bot-to-Bot Communication Mode.

Если окно браузера не открылось, откройте вручную:
http://127.0.0.1:17632/

word_template.docx — исходный шаблон для Word-направления.
Папки data и logs нельзя удалять: в них находятся очереди, настройки и журнал диагностики.
