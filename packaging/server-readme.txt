EAVC CONNECT — ЦЕНТР УПРАВЛЕНИЯ

1. Распакуйте архив в постоянную папку на мини-ПК.
2. Дважды нажмите EAVC Connect Center.exe.
3. В разделе «Связь» укажите бота центра и ID закрытой группы обмена.
4. В разделе «Получатели» настройте группы Telegram и папку Word.
5. В разделе «Точки» создайте отдельный файл настроек для каждой рабочей точки и передайте его оператору.
   Если файл понадобится снова, нажмите «Скачать файл настроек» в карточке существующей точки.
6. Проверьте правила в разделе «Маршруты» и опубликуйте их.

Установка, Python, Go, VPN, белый IP и права администратора не нужны.
Для каждой рабочей точки нужен отдельный Telegram-бот и отдельная тема группы обмена.
У бота центра и ботов рабочих точек в BotFather должен быть включён Bot-to-Bot Communication Mode.
Боту центра в группе обмена нужно право удалять сообщения: обработанные служебные файлы очищаются автоматически.

Если окно браузера не открылось, закройте программу и снова дважды нажмите
EAVC Connect Center.exe. Программа сама откроет защищённую ссылку интерфейса.

word_template.docx — стандартный шаблон для Word-направления. Не удаляйте метки в двойных фигурных скобках: центр заменяет их данными перехвата.
Папки data и logs нельзя удалять: в них находятся очереди, настройки и журнал диагностики.
