# EAVC Connect

Новая реализация `EAVC Connect — Рабочая точка` и `EAVC Connect — Центр управления` на Go. Старый код на Python в этот репозиторий не входит.

## Что делает система

- `EAVC Connect — Рабочая точка` только читает базу EAVC, сохраняет события в собственной очереди и передаёт зашифрованные пакеты через закрытую Telegram-супергруппу.
- `EAVC Connect — Центр управления` принимает пакеты, исключает дубликаты, применяет настраиваемую матрицу маршрутов, публикует сообщения в целевые Telegram-группы и создаёт документы Word для файловых направлений.
- Событие разрешено впервые доставлять только 30 минут от времени изменения в EAVC. Очереди сохраняют порядок: зависшая отправка не позволяет более позднему сообщению обогнать её в том же потоке.
- Для работы через интернет не требуются белый IP, проброс портов, VPN или установка системной службы.

Обе программы поставляются как переносимые папки. Оператор распаковывает папку, запускает EXE и загружает готовый файл конфигурации.

## Структура проекта

- `cmd` — две точки запуска: клиент и сервер;
- `internal` — весь код программы по слоям чистой архитектуры;
- `assets` — проверенный шаблон Word;
- `packaging` — короткие инструкции, вкладываемые в ZIP;
- `scripts` — сборка и проверка переносимых архивов;
- `docs` — архитектура и руководства;
- `go.mod` и `go.sum` — описание Go-модуля и точные версии библиотек.

Скрытая папка `.git` содержит локальную историю. IntelliJ IDEA не показывает её в дереве проекта, но использует её для веток и журнала. Готовые программы находятся не в исходниках, а в соседней папке `Intercept-Releases`.

## Сборка переносимых архивов

Промышленная сборка безопасно останавливается без сертификата Authenticode и
явно указанного внешнего ключа обновлений:

```powershell
.\scripts\build-release.ps1 -Version 1.0.0 `
  -SigningCertificateThumbprint '<отпечаток сертификата>' `
  -UpdateSigningKeyPath 'E:\ProtectedKeys\eavc-update-ed25519.key'
```

Только для изолированного стенда разрешён отдельный явный режим:

```powershell
.\scripts\build-release.ps1 -Version 0.2.0-rc42 -LabBuild
```

Скрипт проверяет код, собирает Windows x64 без CGO, создаёт два ZIP, публикует SHA-256, подписанный манифест выпуска и запускает оба приложения из чисто распакованных папок с пробелами и кириллицей. Результат сохраняется рядом с проектом в `Intercept-Releases\<версия>`, не засоряя исходники. Если системная папка кэша недоступна, сборка автоматически использует служебную папку рядом с рабочей областью.
