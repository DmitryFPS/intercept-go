# Intercept

Новая реализация `InterceptClient` и `InterceptServer` на Go. Старый код на Python в этот репозиторий не входит.

## Что делает система

- `InterceptClient` только читает базу EAVC, сохраняет события в собственной очереди и передаёт зашифрованные пакеты через закрытую Telegram-супергруппу.
- `InterceptServer` принимает пакеты, исключает дубликаты, применяет настраиваемую матрицу маршрутов, публикует сообщения в целевые Telegram-группы и создаёт документы Word для файловых направлений.
- Для работы через интернет не требуются белый IP, проброс портов, VPN или установка системной службы.

Обе программы поставляются как переносимые папки. Оператор распаковывает папку, запускает EXE и загружает готовый файл конфигурации.

## Сборка переносимых архивов

```powershell
.\scripts\build-release.ps1 -Version 0.1.0
```

Скрипт проверяет код, собирает Windows x64 без CGO, создаёт два ZIP, публикует SHA-256 и запускает оба приложения из чисто распакованных папок с пробелами и кириллицей.
