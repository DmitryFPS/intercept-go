1 · @BOTFATHER

Создайте и настройте четыре отдельных бота

Проверка подлинности

Откройте поиск Telegram, введите @BotFather и выберите официальный аккаунт с синей отметкой. Не используйте похожие имена и сторонних «создателей ботов».

1.1. Создание каждого бота

  1. Откройте личный диалог с @BotFather и нажмите START / Запустить, если диалог новый.
  2. Отправьте команду /newbot.
  3. На вопрос Choose a name for your bot введите отображаемое имя. Для текущего стенда по очереди создавались: Intercept Lab Server, Intercept Lab Textile, Intercept Lab Selidovo, Intercept Lab Vesyoloe.
  4. На вопрос об username введите уникальное латинское имя, оканчивающееся на bot. Текущие username перечислены в шаге 0.
  5. BotFather пришлёт токен. Скопируйте его целиком, без пробелов и кавычек, и сразу пометьте, какому боту он принадлежит. Не вставляйте токен в общий чат.
  6. Повторите шаги для всех четырёх ролей. Один токен нельзя использовать сразу для двух точек.

1.2. Настройки через /mybots

/mybots→выбрать нужного бота→Bot Settings
  1. Откройте Allow Groups? (или команду /setjoingroups) и установите Enable. Сделайте это для центра и всех трёх точек.
  2. Откройте Bot-to-Bot Communication и включите режим у всех четырёх ботов. Без этого точечные боты и бот центра не смогут надёжно обмениваться пакетами в одной группе.
  3. Для Intercept Lab Server откройте Group Privacy (или /setprivacy) и выберите Turn off / Disable. На текущем стенде центральный бот также является администратором технической группы.
  4. Для ботов точек выключать Group Privacy не требуется: они только отправляют пакеты в назначенную тему.
  5. После изменения Group Privacy удалите центрального бота из технической группы и добавьте заново, если BotFather прямо сообщает, что настройка применится после повторного добавления.

2 · ТЕХНИЧЕСКАЯ ГРУППА

Настройте Intercept Transport Test

Состав группы на текущем стенде

Lynn — владелец; Intercept Lab Server — администратор; Intercept Lab Textile, Intercept Lab Selidovo и Intercept Lab Vesyoloe — обычные участники.

Снимок состава намеренно не публикуется: на этой странице Telegram одновременно показывает приватную ссылку-приглашение. Токены и приватные ссылки не должны попадать в инструкцию.

  1. Telegram → меню → Новая группа. Название текущего стенда: Intercept Transport Test.
  2. Откройте Управление группой / Изменить и включите Темы. Группа должна оставаться частной.
  3. Создайте темы с точными именами: Текстиль, Селидово, Весёлое. Тему General не удаляйте.
  4. Добавьте Intercept Lab Server и три бота точек.
  5. Назначьте Intercept Lab Server администратором. Нужны права читать/отправлять сообщения, отправлять файлы, удалять служебные сообщения и работать с темами.
  6. Ботов точек оставьте обычными участниками с правом отправлять сообщения и файлы. Каждая точка получает только ID своей темы.
  7. Не включайте медленный режим: регулирование частоты выполняет EAVC Connect, а медленный режим создаёт лишнюю задержку транспортной очереди.

3 · TELEGRAM-ПОЛУЧАТЕЛИ

Создайте рабочие группы АэродромТест и ШабашкаТест

  1. Создайте две отдельные частные группы: АэродромТест и ШабашкаТест. Включите в каждой Темы.
  2. Добавьте только Intercept Lab Server и назначьте его администратором. Боты рабочих точек в группы получателей не добавляются.
  3. Оставьте тему General. Она используется маршрутом «Новые и неопознанные позиции».
  4. Создайте отдельную тему для каждой корректной позиции, которую должен получать адресат. Название темы — для человека; маршрутизация выполняется по числовому ID темы.
  5. Ошибочная или новая позиция должна попасть только в настроенный General. Для неё не создаётся DOCX и она не отправляется в 39-ю точку.
  6. Для Word-получателя 39-ка Telegram-группа, бот и тема не нужны: на сервере задаются папка, DOCX-шаблон и обозначение.

Ограничения Telegram и защита от блокировки

Не ускоряйте очередь вручную

Telegram рекомендует не отправлять в один чат чаще примерно одного сообщения в секунду; в группах действует более жёсткий длительный предел, а массовая рассылка без платного режима ограничена примерно 30 сообщениями в секунду. EAVC Connect выдаёт задания последовательно, делает паузы и при ответе 429 Too Many Requests ждёт указанное Telegram время Retry-After.

  1. Не запускайте несколько экземпляров центра с одним токеном: они будут конкурировать за одну очередь и лимиты одного бота.
  2. Не нажимайте повторную отправку многократно. Сначала откройте «Ожидает отправки» и посмотрите состояние задания.
  3. При временной недоступности Telegram оставьте центр запущенным: повтор выполняется автоматически, без ручного копирования сообщения.
  4. При нагрузочном тесте контролируйте отсутствие дублей, рост очереди, ответы 429 и последующее полное опустошение очереди.
6 · ПРИЁМКА

Проверяйте по порядку, а не сразу большим потоком

  1. С каждой точки отправьте один обычный перехват корректной позиции. Убедитесь, что он появился в нужной теме один раз.
  2. Проверьте сообщение с 3–8 корреспондентами и 2–4 временными блоками.
  3. Отредактируйте перехват: прежнее Telegram-сообщение должно измениться, а внизу после пустой строки должна появиться отметка (отредактировано ЧЧ:ММ:СС).
  4. Проверьте отложенный перехват и новую/ошибочную позицию. У ошибочной позиции не должно быть Word-документа.
  5. Только после одиночных проверок запускайте нагрузочный тест. EAVC Connect хранит очередь, соблюдает паузы Telegram и учитывает Retry-After при ответе 429.

Если не работает

Нет подтверждения центраПроверьте Bot-to-Bot у обоих ботов, Group Privacy центра, права администратора, ID группы и ID темы точки.
Ошибка Telegram / timeoutЭто может быть сеть или временная недоступность API. Не нажимайте отправку многократно: очередь повторит попытку сама.
Сообщение не в той темеПерепроверьте ID темы в опубликованном маршруте. Одинаковые названия тем не означают одинаковые ID.
Появились дублиСкачайте диагностику центра и точки; зафиксируйте время, позицию и тему. Повторно не запускайте тот же тест до анализа.
Ответ 429Оставьте программы запущенными. EAVC Connect должен выдержать указанную Telegram паузу и продолжить без дублей.
