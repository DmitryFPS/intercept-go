Группа обмена — техническая. Группы получателей — рабочие. Не используйте одну и ту же группу для обеих ролей.

1 · BOTFATHER

Создайте отдельного бота для каждой роли

  1. В @BotFather отправьте /newbot.
  2. Задайте понятное имя. Username должен состоять из латинских букв/цифр/подчёркивания и оканчиваться на bot.
  3. Скопируйте выданный токен. Для каждого бота токен уникален.
  4. Через /mybots → нужный бот → Bot Settings включите Bot-to-Bot Communication у бота центра и каждого бота точки.
  5. У бота центра откройте Group Privacy и отключите privacy mode. После изменения удалите бота центра из группы и добавьте заново, если BotFather попросит это сделать.

2 · ГРУППА ОБМЕНА

Создайте закрытую группу с темами

  1. Создайте частную группу. Публичная ссылка не нужна.
  2. В настройках группы включите Темы.
  3. Создайте отдельную тему для каждой рабочей точки. Не направляйте две точки в одну тему.
  4. Добавьте бота центра и всех ботов рабочих точек.
  5. Боту центра выдайте права отправлять и удалять сообщения, а также управлять темами. Ботам точек разрешите отправлять сообщения и файлы.
  6. Не включайте медленный режим в технической группе — он задерживает очередь.
3 · ID ГРУППЫ И ТЕМ

Получите числа без сторонних ботов

  1. Откройте нужную тему и отправьте обычное тестовое сообщение от своего аккаунта.
  2. Нажмите правой кнопкой по сообщению → Копировать ссылку.
  3. Для ссылки вида t.me/c/1234567890/321/450 ID группы равен -1001234567890, а ID темы — 321.
  4. Повторите для каждой темы и запишите соответствие «точка → ID темы».
  5. Если ссылка имеет другой вид или тема General не содержит отдельного номера, создайте отдельную техническую тему и используйте её — не угадывайте ID.

Контрольный список перед работой

Если что-то не работает

Центр не видит пакетыПроверьте Bot-to-Bot, Group Privacy, права центра, ID группы и тему конкретной точки.
Точка не получает подтверждениеBot-to-Bot должен быть включён и у бота центра, и у бота точки. Проверьте username серверного бота в конфигурации.
Сообщение попало не в ту темуСкопируйте ссылку на сообщение именно из нужной темы и перепроверьте ID темы.
Ошибка 429Не перезапускайте отправку многократно. Программа сама выдерживает паузу Telegram и повторяет попытку.
После изменения BotFather ничего не изменилосьУдалите бота из группы, добавьте заново и нажмите «Обновить» в EAVC Connect.
Ограничения Telegram, уже учтённые программойне более 1 сообщения/с в один чатне более 20 сообщений/мин в группуобщая рассылка около 30 сообщений/с

При ответе 429 программа использует рекомендованную Telegram паузу, сохраняет очередь и не создаёт дубли.

Официальная справка Telegram

Инструкция сверена с официальной документацией Telegram. Интерфейс Telegram может немного менять внешний вид, но названия настроек и требуемый результат остаются теми же.
